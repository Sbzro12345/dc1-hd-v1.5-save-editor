NOTE: Defender Chronicles HD v1.5 is a little-endian 32-bit game




Token Count:
- takes up 4 bytes (DWORD)
- starts at 53 bytes before the General Hero Identifier (DWORD)
- [Tokens] [49 bytes] 47 65 6E 65 72 61 6C 00


# When anything below references "Hero Identifier", it includes the null string terminator 00
# Hero Identifier, like other strings in DC1, are dynamic in length
General Hero Identifier - 47 65 6E 65 72 61 6C 00
Melwen Hero Identifier - 4D 65 6C 77 65 6E 00
Elwin Hero Identifier - 45 6C 77 69 6E 00
Lovell Hero Identifier - 4C 6F 76 65 6C 6C 00


Hero Level:
- 0-indexed
- takes up 4 bytes (DWORD)
- the 4 bytes directly after the Hero Identifier (DWORD)
- e.g. for General: 47 65 6E 65 72 61 6C 00 [Level]


Current EXP:
- takes up 4 bytes (DWORD)
- For the EXP Bar X / Y displayed under Hero Stats, where X is the Current EXP (the 4 bytes here), and Y is the amount of EXP required to level up
- starts 4 bytes after the Hero Identifier i.e. skip 4 bytes after the end of null string terminator
- 47 65 6E 65 72 61 6C 00 [4 bytes] [Current EXP]


???:
4 bytes after Hero Identifier is always FF FF FF FF (-1)


Available Skill Points:
- takes up 4 bytes (DWORD)
- starts 12 bytes after the Hero Identifier i.e. skip 12 bytes after the end of null string terminator
- e.g. for General:  47 65 6E 65 72 61 6C 00 [12 bytes] [Available Skill Points]


Skills [36 bytes]:
- each stat takes up 4 bytes (DWORD)
- General Skills1-3 don't affect Melwen, and vice versa
- for General: starts 16 bytes after the Hero Identifier, while it is 28 bytes for Melwen
- for General: 47 65 6E 65 72 61 6C 00 [16 bytes] [Skill1] [Skill2] [Skill3] [Skill4] [Skill5] [Skill6] [12 bytes]
- for Melwen: 4D 65 6C 77 65 6E 00 [28 bytes] [Skill4] [Skill5] [Skill6] [Skill1] [Skill2] [Skill3]

Mythic+ Maps Clears Block
- array of 9 maps. Each map contains 8 bytes
  - Number of stars icon. (Heroic is 6, Legend+ is 7) [4 bytes]
  - Number of clears past Mythic, 0-indexed. e.g. Mythic R0 is 0, Demigod R0 is 40 [4 bytes]
  - In order: Greatsands, Cloudpass, Marshwood, Silverkeep, Breewich, Gardbridge, Tarnwood, Helegom, Siria
  - Changing number of stars icon with Save Editor will automatically unlock their associated unlocks, like as if beating normally. Also increases Reputation. But, does not award Quest Items Regalia or Ale Bottle
  - Gardbridge can be set even if Secret is not unlocked. But, if Secret is not unlocked, level is not playable and no stars will be displayed
  - To unlock Legend, all levels' stars icon must be minimum 6.
  - To unlock Mythic+, all levels' stars icon must be minimum 7.
  - General's Map Array: [01 00 00 00 FF FF FF FF][149 bytes][arr[maps]] - look for the closest 01 00 00 00 FF FF FF FF block above Elwin String Identifier











Equipment
- 01 00 00 00 (Fixed 4 bytes)
- Equipment Slot [4 bytes]: 0 for Headpiece, 1 for Weapon, 2 for Chestpiece, 3 for Accessory, FF FF FF FF for unequipped which means ignore the proceeding String Identifier and 156 bytes. Any other value makes the item equippable. Setting a wrong slot to an equipped item causes it to be unequippable.
- String Identifier (Dynamic length)
- Followed by 148 misc. bytes
  - Sprite Number [4 Bytes]
  - Token Value [4 Bytes] - FF FF FF FF means Quest Item
  - Prefix Count [4 Bytes] - Naturally no cap.
  - Suffix Count [4 Bytes] - Naturally capped at 1. Save editor can lift cap.

  - Reputation Tier [4 bytes]
    Multipliers affect stats, colour and price ONLY during generation.
    Using a save editor to modify Grade only affects colour.
      0 = Rusty (x0.5). Same Rep. behaviour as 1.
      1 = Baseline (x1). no requirement, but the game then compares the item
               name against three hardcoded strings (Contains check, not Equals):
                 "Tahl Asel"                -> Rep. Renowned
                 "Regalia of Dominion"      -> Rep. Glorious
                 "Merry Roper's Ale Bottle" -> Rep. Legend
      2 = Rep. Respected - Superior (x2)
      3 = Rep. Distinguished - Elite (x3)
      4 = Rep. Renowned - Legendary (x4)
      5 = Rep. Legend - Mythic (x5)
      6+ = Rep. Immortal - Demigod (x6)
      Celebrated, Eminent and Glorious cannot be set by code.
      Glorious is hardcoded for strings containing "Regalia of Dominion"

  - Grade [4 bytes]
    Multipliers affect stats, colour and price ONLY during generation.
    Using a save editor to modify Grade only affects colour.
      0 = none        x1.0
      1 = Defective   x0.8
      2 = Exceptional x1.1
      3 = Flawless    x1.2
      4 = Masterpiece x1.3
      5 = Ultimate    x1.5

  - Which Hero? [4 bytes]:
      Bitmask, one bit per hero. From Right to Left, Bit 0 is General, bit 2 is Melwen.
      Bits 1 and 3 are Elwin and Lovell, which have no visible effect in HD v1.5.
      Where X is either 0 or 1, General only = X0X1, Melwen only = X1X0, Both = X1X1.
      e.g. 1111 is 0x0F, and it works for Both heroes

  - array of 10 Effect entries. Each entry contains 12 bytes:
    - Effect - 4 bytes
    - Target - 4 bytes
    - Value - 4 bytes (some effects only takes 0 for a valid value)
    NOTE: array may be populated with Effect 00 00 00 00, but non-zero Target and/or Value.
          This is equivalent to all zero, since if Effect is 00 00 00 00, it is ignored.
    NOTE: ensure that there are no more non-zero Effects after the 1st 00 00 00 00 Effect!
